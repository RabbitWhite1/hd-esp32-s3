# Licensing notes

Project source is MIT-licensed. New project source files should carry the same
`SPDX-License-Identifier: MIT` header as the existing files.

Two paths are exceptions and should not receive the project header:

- `src/ExternLib/` contains Espressif's Apache-2.0 `esp_codec_dev` and `codec_board` components.
- `src/Music/canon.h` is a generated PCM byte array of Canon in D.

The Claude and OpenAI marks are rendered as one-bit icons to identify their respective usage gauges.
Those marks remain the property of Anthropic and OpenAI.
